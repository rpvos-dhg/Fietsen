    Bewaard op dit apparaat

      Blijft in deze browser staan, ook na een herstart. Er gaat niets naar een server.

      Instellingen en opslag

      Zonder werkt alles; een cache-server deelt opgehaalde gebieden tussen je apparaten en scheelt wachttijd bij een nieuw gebied. Moet https zijn.

      Kaartlagen: PDOK Regionale Fietsnetwerken (WMS) en PDOK BRT Achtergrondkaart. Routegeometrie uit het OpenStreetMap-knooppuntennetwerk, omdat PDOK deze dataset alleen als kaartbeeld publiceert.
